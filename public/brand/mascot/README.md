# 이집이(ejipy) Mascot 자산 규격

이 디렉터리는 캐릭터 `이집이` 이미지 자산이 배치될 위치다. **아직 실제
이미지 파일은 없다** — BRAND STEP 56-B2는 구조/규격만 정의하고, 실제
캐릭터 일러스트 제작은 별도 STEP(사용자 승인 시안 확정 후)에서
진행한다. AI 시각화 보드의 캐릭터 이미지를 crop해서 이 위치에 그대로
쓰지 않는다 — 그건 방향 참고용 시안이지 production 자산이 아니다.

## 필요 포즈 (파일명 규칙)

`docs/development/56-brand-system-application-plan.md`의 "STEP 56-B
자산 제작 항목"과 동일한 우선순위를 따른다.

| 파일명 | 포즈 | 용도 | 우선순위 |
|---|---|---|---|
| `ejipy-default.webp` | 기본/중립 | empty state 기본 | 중 |
| `ejipy-search.webp` | 돋보기 들고 찾는 중 | AI 조건검색 대기(6-3) | **최우선** |
| `ejipy-analyze.webp` | 노트/차트 정리 중 | section loading 보조(6-2) | 중 |
| `ejipy-loading.webp` | 걷는/일하는 동작 | `FullPageLoader` global loading | 높음 |
| `ejipy-empty.webp` | 두리번거리는 기본 포즈 | 검색결과없음/최근본단지없음 | 높음 |
| `ejipy-guide.webp` | 안내하는 포즈(손짓 등) | onboarding, 준비 중 안내 | 낮음 |
| `ejipy-error.webp` | (사용 자제 — 아래 참고) | — | 보류 |

`ejipy-error`는 우선순위를 매기지 않는다 — 56-A 문서의 "6-5. Error /
Retry" 전략상 에러 상태는 신뢰감을 캐릭터보다 우선하기로 설계돼 있어
(과도한 귀여움 금지), 에러 화면에 캐릭터를 쓸지 자체를 STEP 57에서
다시 판단한다.

## 파일 포맷

- **주 포맷: WebP**(투명 배경) — 압축률이 좋고 Next/Image가 기본
  지원.
- 필요 시 구형 브라우저 대응용 PNG fallback을 같은 이름으로 병행
  (`ejipy-search.png`).
- 배경은 투명이어야 한다(카드/오버레이 등 다양한 배경 위에 얹히므로).
- 비율: 정사각형(1:1) 기본. 포즈에 따라 세로가 긴 구도가 자연스러우면
  예외를 문서화하고 사용.
- 원본 해상도는 1024px 이상으로 확보해 둔다(다운스케일은 자유롭지만
  업스케일은 화질이 깨진다) — 실제 화면에는 Next/Image로 필요한
  크기만 최적화해서 서빙한다(§ `56-brand-assets.md`의 "image
  optimization" 참고).
- 파일 하나당 200KB를 넘기지 않는 것을 권장(초기 로딩 성능 원칙,
  `56-brand-assets.md` "성능 원칙" 참고). 넘으면 재압축/치수 축소
  검토.

## 적용 시 주의

- 이 README가 정의한 파일명을 실제 자산이 도착하면 그대로 사용한다
  (코드에서 참조할 경로를 예측 가능하게 하기 위함).
- 캐릭터가 없는 상태에서도 기존 UI(텍스트 기반 로딩/empty 문구)가
  깨지지 않아야 한다 — 이미지는 항상 선택적 보강 요소로 취급한다.
- 실제 코드 적용은 STEP 57 이후, 각 파일이 이 디렉터리에 실제로
  존재하는 것을 확인한 뒤에만 진행한다(추측으로 경로를 참조하지
  않는다).
