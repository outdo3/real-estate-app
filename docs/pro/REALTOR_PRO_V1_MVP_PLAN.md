# REALTOR PRO V1 — MVP 7일 계획 & 로드맵

- 상태: **계획 문서.** Day 1 착수 전 schema/migration 승인(A1·A2, ARCHITECTURE §11) 필요.
- 대상: 초대받은 테스트 중개사 5~10명(수동 인증, 전원 Pro 기능 BETA_GRANT)
- 배포 안전: `PRO_ENABLED` 서버 flag 기본 false + 테스트 중개사 allowlist. `main` push는 production 배포로 간주.

## 1. MVP 범위

| 포함 (MVP_CORE) | 제외(명시적 보류) |
|---|---|
| 1. 중개사 프로필 + 신청/수동 인증 | 결제·구독 과금 |
| 2. 비공개 매물 노트(단지 aptSeq 연결, Unit Master 면적) | 팀/사무소 계정, 조직 관리 |
| 3. 고객 CRM(구조화 조건 + 메모 분리, 팔로업 1종) | 음성/STT, 고급 AI 요약·추천 |
| 4. 기본 매칭(hard filter + soft 가중, 이유 표시) | 공개 매물 마켓플레이스 |
| 5. 기본 브리핑(스냅샷 + 토큰 링크 + 만료/회수) | 카카오 API 자동 발송·알림톡 |
| (+) 간단 대시보드: 재연락·매칭·만기 3섹션 | 회계/정산, 계약서, 전자서명, 브리핑 이미지 저장 |

## 2. Day-by-day (1인 개발 기준)

| Day | 작업 | 산출물 / 검증 |
|---|---|---|
| **0 (사전)** | 승인: schema 초안·암호화 방식·Header 하단 탭 교체·break-glass 정책. 약관/처리위탁 초안 법률 검토 요청 | 승인 기록 `DECISIONS.md` |
| **1** | migration(신규 10테이블, revoke+RLS ON, CHECK) 작성·로컬 검증 → 승인 후 적용. `src/lib/pro/access.ts`(`requireRealtor`, `assertOwner`), `PRO_ENABLED` flag, `/pro` layout 가드, noindex | 소유권 헬퍼 단위 테스트(타인 id → 404) |
| **2** | 중개사 신청(`/pro/apply`) + 관리자 심사(`/admin/pro/applications`) + 감사로그. `/my` 진입 카드, Pro 하단 탭 | 상태 전환 테스트, 360/375/390 QA |
| **3** | 매물: 단지 검색(기존 APARTMENT 결과 계약) → aptSeq·면적(Unit Master) → 가격·상태 입력, 목록/상세/노트/가격이력, 비밀번호 패턴 경고, 연락처 암호화 | aptSeq 없는 단지 저장 경로, 가짜 평형 없음 테스트 |
| **4** | 고객 CRM: 목록/상세/조건 세트/팔로업, 동의 상태 필드, 삭제(soft) | 조건↔메모 분리, 삭제 후 404 |
| **5** | 매칭 엔진 순수 함수 + 사유 생성 + 저장/재계산 API + 고객·매물 화면 매칭 목록 | 엔진 golden 테스트(예산/면적/UNKNOWN 분모 제외/정보부족) |
| **6** | 브리핑: 스냅샷 조립(공공 데이터 enablement 게이트), 토큰 발급(해시 저장), `/b/[token]` 공개 뷰, 만료/회수, 비표시 필드 테스트. 대시보드 3섹션 | 스냅샷에 소유자·호수·메모·타 고객 없음 테스트, 닫힌 지역 실거래 미노출 테스트 |
| **7** | 통합 QA(모바일 3폭, 데스크톱), `tsc`·lint·build, 공개 read path가 `realtor_*` 미참조 확인, 테스트 중개사 온보딩 가이드, `docs/development` STEP 기록 | 실제 실행 결과만 보고 |

- 여유 없음: 7일은 **범위 고정 시에만** 가능. 막히면 대시보드 → 브리핑 공개 뷰 디자인 순으로 축소.

## 4. 로드맵 (MVP 이후 2~3주)

| Phase | 기간 | 내용 | 필요 승인 |
|---|---|---|---|
| **1. MVP** | 1주(7 dev-days) | §2 전체, 테스트 중개사 5~10명 초대 | **schema/migration 승인**, Header 하단 탭 교체, 법률 검토 요청(약관·처리위탁·동의) |
| **2. 매칭·브리핑 고도화** | 1주(~6 dev-days) | 자동 재계산, 고객별 가중치, 다중 조건 세트, 브리핑 카드 이미지·로고·기간, 대시보드 8섹션, 팔로업 반복 | 추가 컬럼 필요 시 **migration 승인** |
| **3. Free/Pro 한도 + 구독** | 1주(~6 dev-days) | `plan-limits` 적용, 다운그레이드 읽기전용, PG 연동·웹훅 검증, 청약철회/환불 | **결제 도입 승인**(외부 유료 의존성), PG 선정, 약관·전자상거래 **법률 검토**, 가격 결정 |
| **4. 실사용 베타 + 분석** | 0.5~1주(~4 dev-days) + 운영 | 분석 이벤트(PII 없음), 보존/삭제 배치, 내보내기, break-glass 운영 절차, 공개 베타 신청 | 외부 중개사 확대 전 **개인정보 처리방침 개정·법률 검토 완료**, `PRO_ENABLED` production ON 승인 |

- 총 추정: MVP 7 dev-days + Full V1 약 25~26 dev-days(결제 포함). 결제 제외 시 약 21.5.
- 매 Phase 종료: `docs/development/`에 STEP 문서, `CHANGELOG.md`, 필요한 결정은 `DECISIONS.md`.

## 5. MVP 성공/중단 기준

| 판단 | 기준(가설) |
