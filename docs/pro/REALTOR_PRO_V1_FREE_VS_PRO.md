# REALTOR PRO V1 — Free vs Pro 경계 (가설)

- 상태: **가설 문서.** 가격·한도는 확정값이 아니며 베타 인터뷰/사용 데이터로 검증 후 결정한다.
- 결제 연동은 MVP 범위 밖(Phase 3, 별도 승인).

## 1. 설계 원칙

1. **Free는 "업무에 실제로 써볼 수 있는" 수준이어야 한다.** 너무 좁으면 가치를 체험하지 못해 전환이 일어나지 않는다.
2. **Pro의 차별점은 "자동화·반복 업무 절감"에 둔다.** 데이터 보관 자체(이미 입력한 매물·고객)를 인질로 잡지 않는다 — 다운그레이드 시 읽기/내보내기는 항상 허용.
3. **개인정보 보호 기능은 등급과 무관하게 동일**하다(감사로그, 삭제, 내보내기, 공유 만료). 보안을 유료 기능으로 팔지 않는다.
4. 한도는 서버에서 검증한다(클라이언트 표시만으로 제한하지 않음).

## 2. 초기 가설 대비 조정

| 항목 | 초기 가설 | 권장 V1 경계 | 이유 |
|---|---|---|---|
| Free 매물 한도 | 5건 | **활성 매물 10건** | 5건은 1주일 업무도 못 담아 "노트" 가치 체험 불가. 비활성(보관) 매물은 한도 제외 |
| Free CRM | 없음(full CRM 없음) | **고객 5명, 기본 조건 입력 허용** | 매칭 가치를 체험하려면 고객이 최소 몇 명은 있어야 함 |
| Free 매칭 | 없음 | **수동 매칭만**(고객 화면에서 "지금 맞는 매물 보기" 버튼, 계산 결과 상위 3건) | 결정적 엔진은 비용이 낮음. 자동 알림/백그라운드 재계산을 Pro로 |
| Free 브리핑 | 2/일 | **3/일, 이집 기본 로고, 만료 7일 고정** | 공유 받은 고객이 이집을 알게 되는 유입 경로이기도 함 |
| Pro 매물·고객 | 높은 한도 | **활성 매물 300 / 고객 500 (soft cap, 남용 방지용)** | "무제한" 표기는 운영 리스크 — 실제 상한은 남용 방지 수준으로 |

## 3. 권장 V1 기능표

| 기능 | Free (인증 중개사) | Pro |
|---|---|---|
| 중개사 프로필 | O | O |
| 활성 비공개 매물 | 10건 | 300건(soft cap) |
| 매물 기본 메모 | O | O |
| 매물 상세 비공개 노트(이력형 노트, 가격 변경 이력) | 최근 1건만 | O(전체 이력) |
| 매물 태그·검색 | 기본 검색(단지명/거래유형) | 태그·필터·정렬 |
| 고객 CRM | 5명 | 500명(soft cap) |
| 고객 조건 수 | 고객당 조건 세트 1개 | 고객당 조건 세트 3개(예: 매매안/전세안) |
| 매칭 | 수동 조회, 상위 3건 | 자동 재계산(매물/고객 변경 시) + 대시보드 알림 + 전체 목록 |
| 매칭 이유 설명 | O | O |
| 팔로업 리마인더 | 고객당 1개 | 무제한 + 반복 |
| "오늘 해야 할 일" 대시보드 | 일부 섹션(재연락·만기) | 전체 섹션 |
| 브리핑 생성 | 3건/일 | 무제한(남용 방지 rate limit만) |
| 브리핑 커스터마이즈 | 중개사 이름·연락처 | + 사무소 로고, 강조 문구, 만료기간 선택(1~30일) |
| 브리핑 열람 여부 | O | O + 열람 시각 |
| 데이터 내보내기(CSV) / 삭제 | O | O |
| 감사로그·공유 만료·즉시 회수 | O | O |

## 4. 가격 가설 (확정 아님)

| 안 | 월 가격(가설) | 검증 질문 |
|---|---|---|
| A | 19,900원 | 1인 중개사 진입 장벽 최소화. 전환율 확인 |
| B | 29,900원 | 자동매칭·브리핑 가치가 충분하면 수용 가능한가 |
| 연간 할인 | 미정 | Phase 4 이후 |

- 베타(MVP) 기간은 **전원 Pro 기능 무료 제공**, 한도 정책은 flag로 끄고 켤 수 있게 한다(ARCHITECTURE §4).
- 가격/결제/환불/청약철회 조건은 전자상거래·약관 관련 **법률 검토 필요**.

## 5. 다운그레이드/해지 정책(설계)

| 상황 | 동작 |
|---|---|
| Pro → Free | 기존 데이터 보존. 한도 초과분은 **읽기 전용**(수정·신규 매칭 불가), 삭제하지 않음 |
| 결제 실패 유예 | 7일 유예(가설) 후 Free 한도 적용 |
| 해지/탈퇴 | 내보내기 안내 → 보존기한 정책에 따라 삭제(ARCHITECTURE §7.5) |
| 활성 브리핑 링크 | 다운그레이드해도 만료일까지 유지, 로고만 기본으로 교체 |

## 6. 한도 적용 지점

| 한도 | 검증 위치 |
|---|---|
| 활성 매물 수 | `POST /api/pro/listings`, 매물 활성화 PATCH |
| 고객 수 | `POST /api/pro/customers` |
| 브리핑/일 | `POST /api/pro/briefings` (KST 달력일 기준 count) |
| 자동매칭 | 백그라운드 재계산 트리거 자체를 Pro에서만 실행 |

모든 한도 값은 코드 상수 한 곳(`src/lib/pro/plan-limits.ts`, 향후)에서 정의하고 테스트로 고정한다.
