# 도메인/서비스명 가변형 SEO 인프라 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `siteConfig` 하나로 사이트 전체 SEO가 따라가게 만들고, 실거래가/시장통계/학군정보/커뮤니티 게시글/단지 상세 5개 페이지에 동적 title/description/OG 태그를 부여하며, 동적 `robots.txt`/`sitemap.xml`을 추가한다.

**Architecture:** 대상 5개 페이지는 전부 `'use client'` 컴포넌트라 `generateMetadata`를 못 쓴다. 각 라우트를 "서버 `page.tsx`(메타데이터 전담) + 그대로 이동한 클라이언트 `*-client.tsx`(기존 로직/동작 무변경)"로 분리한다. `/stats`, `/school`은 `sido`/`sigungu` 쿼리파라미터를 받아 초기 지역을 하이드레이션하고 메타데이터에도 반영한다. `sitemap.ts`는 정적 경로 + 지역 조합(`REGION_DATA`) + 커뮤니티 글(Prisma)을 합쳐서 반환하며, 빌드 타임에 DB를 건드리지 않도록 `force-dynamic`으로 명시한다.

**Tech Stack:** Next.js 16.3.0 (App Router), React 19, TypeScript, Prisma 5 (PostgreSQL), 기존 `RegionContext`/`RegionSelectModal`/`region-utils.ts`.

## Global Constraints

- 기존 클라이언트 컴포넌트의 동작(로직/렌더링)은 변경하지 않는다 — 순수 구조 이동 + 메타데이터/URL 하이드레이션 추가만 한다.
- 이 프로젝트에는 테스트 프레임워크가 없다(package.json에 jest/vitest 없음). 검증은 `npm run build`(타입체크 포함)와 수동 스모크 테스트(dev 서버 + curl/브라우저)로 한다.
- `sitemap.ts`는 Prisma를 호출하지만 로컬 `.env`의 `DATABASE_URL`이 플레이스홀더라 빌드 타임에 DB에 접근하면 안 된다 → `export const dynamic = 'force-dynamic'` 필수.
- `siteConfig` 기본 사이트명은 `'아파트써처'` (기존 브랜딩과 일치).
- `TradeHistory` 기반 "주요 단지" 사이트맵 항목은 이번 범위에서 제외한다.
- `tsconfig.json`의 경로 별칭은 `@/*` → `./src/*`.
- 마지막 태스크에서 `npm run build` 클린 통과 확인 후 `git push origin main`까지 실행한다(요청서 4번 항목에 명시된 범위).

## Task 2: `region-utils.ts`에 지역명 → lawdCd 변환 헬퍼 추가

지역 쿼리파라미터(`sido`, `sigungu` 이름)로 진입했을 때 `RegionContext`가 요구하는 `lawdCd`(5자리 법정동코드)를 얻기 위한 헬퍼. `RegionSelectModal.tsx`의 `selectSido`/`selectSigungu`(REGCODE_PROXY 조회 후 이름 매칭)와 동일한 패턴을 재사용한다.

**Files:**
- Modify: `src/lib/region-utils.ts`

**Interfaces:**
- Consumes: `REGCODE_PROXY`(같은 파일에 이미 정의됨)
- Produces: `resolveLawdCdByNames(sido: string, sigungu: string): Promise<string | null>` — Task 4, 5에서 사용.

- [ ] **Step 1: 함수 추가**

`src/lib/region-utils.ts` 끝에 추가:
```ts
type RegcodeEntry = { code: string; name: string };

// URL 쿼리파라미터로 받은 "시/도 전체이름"+"시/군/구 이름"을 RegionContext가 요구하는
// lawdCd(5자리)로 변환한다. RegionSelectModal의 selectSido/selectSigungu와 동일하게
// REGCODE_PROXY를 시도 목록 → 해당 시도의 시군구 목록 순서로 조회해 이름을 매칭한다.
export async function resolveLawdCdByNames(
  sido: string,
  sigungu: string
): Promise<string | null> {
  try {
    const sidoRes = await fetch(`${REGCODE_PROXY}?regcode_pattern=*00000000`);
    const sidoData = await sidoRes.json();
    const sidoEntry = ((sidoData.regcodes || []) as RegcodeEntry[]).find((r) => r.name === sido);
    if (!sidoEntry) return null;

    const sidoCode = sidoEntry.code.substring(0, 2);
    const sigunguRes = await fetch(
      `${REGCODE_PROXY}?regcode_pattern=${sidoCode}*00000&is_ignore_zero=true`
    );
    const sigunguData = await sigunguRes.json();
    const sigunguEntry = ((sigunguData.regcodes || []) as RegcodeEntry[]).find(
      (r) => r.name === `${sido} ${sigungu}`
    );
    return sigunguEntry ? sigunguEntry.code.substring(0, 5) : null;
  } catch (e) {
    console.error('[region-utils] 지역명 -> lawdCd 조회 실패', e);
    return null;
  }
}
```

## Task 9: `sitemap.ts` 추가 (정적 경로 + 지역 조합 + 커뮤니티 글)

**Files:**
- Create: `src/app/sitemap.ts`

**Interfaces:**
- Consumes: `siteConfig`, `absoluteUrl`(Task 1), `REGION_DATA`(`src/lib/regions.ts`, 기존), `prisma`(`src/lib/prisma.ts`, 기존)

- [ ] **Step 1: 작성**

```ts
import type { MetadataRoute } from 'next';
import { prisma } from '@/lib/prisma';
import { absoluteUrl } from '@/config/site';
import { REGION_DATA } from '@/lib/regions';

export const dynamic = 'force-dynamic';

const STATIC_ROUTES: Array<{ path: string; priority: number; changeFrequency: MetadataRoute.Sitemap[number]['changeFrequency'] }> = [
  { path: '/', priority: 1, changeFrequency: 'daily' },
  { path: '/stats', priority: 0.7, changeFrequency: 'daily' },
  { path: '/school', priority: 0.6, changeFrequency: 'weekly' },
  { path: '/community', priority: 0.6, changeFrequency: 'daily' },
];

function buildRegionRoutes(): MetadataRoute.Sitemap {
  const routes: MetadataRoute.Sitemap = [];
  for (const [sido, sigunguList] of Object.entries(REGION_DATA)) {
    for (const sigungu of sigunguList) {
      const query = `sido=${encodeURIComponent(sido)}&sigungu=${encodeURIComponent(sigungu)}`;
      routes.push({
        url: absoluteUrl(`/stats?${query}`),
        changeFrequency: 'daily',
        priority: 0.5,
      });
      routes.push({
        url: absoluteUrl(`/school?${query}`),
        changeFrequency: 'weekly',
        priority: 0.4,
      });
    }
  }
  return routes;
}

const MAX_COMMUNITY_URLS = 500;

async function buildCommunityRoutes(): Promise<MetadataRoute.Sitemap> {
  const posts = await prisma.post.findMany({
    select: { id: true, updatedAt: true },
    orderBy: { createdAt: 'desc' },
    take: MAX_COMMUNITY_URLS,
  });
  return posts.map((post) => ({
    url: absoluteUrl(`/community/${post.id}`),
    lastModified: post.updatedAt,
    changeFrequency: 'never' as const,
    priority: 0.4,
  }));
}

export default async function sitemap(): Promise<MetadataRoute.Sitemap> {
  const staticRoutes: MetadataRoute.Sitemap = STATIC_ROUTES.map((r) => ({
    url: absoluteUrl(r.path),
    priority: r.priority,
    changeFrequency: r.changeFrequency,
  }));

  const communityRoutes = await buildCommunityRoutes();

  return [...staticRoutes, ...buildRegionRoutes(), ...communityRoutes];
}
```
