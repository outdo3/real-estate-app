## 2. Kakao 버스정류장 검색 가능 여부 조사

### A. 전용 category_group_code

Kakao 공식 카테고리 코드는 19종(MT1/CS2/PS3/SC4/AC5/PK6/OL7/SW8/BK9/
CT1/AG2/PO3/AT4/AD5/FD6/CE7/HP8/PM9 + 관련 안내)이며 **버스정류장
전용 코드는 존재하지 않는다.** 임의 코드(`BS0`/`BU0`/`SB0`)로 카테고리
검색을 시도해도 `400 Bad Request`만 반환됨을 실측으로 확인했다.

### B~D. keywordSearch 실측

`geocode-apt.ts`와 동일한 인증 헤더로 `https://dapi.kakao.com/v2/local/
search/keyword.json`을 직접 호출해 `버스정류장`/`정류장`/`정류소`/`버스`/
`시내버스`/`버스승강장` 등 여러 표현을 테스트했다.

**결과: 6개 표본단지 중 4곳(대신푸르지오1차/엘지메트로시티3/남성한빛가든/
고원3단지)은 반경 2,000m 내 위 모든 키워드에서 raw 결과 0건.** 나머지
2곳(명륜아이파크1단지/해운대 표본)에서 나온 결과도 실제로는 아래처럼
**시내버스 정류장이 아니라 "고속,시외버스정류장/터미널"**(장거리 이동용
별도 교통수단)이었다:

| 단지 | 검색어 | 결과 | `category_name` |
|---|---|---|---|
| 명륜아이파크1단지 | 버스정류소 | 동래시외버스정류소(771m) | 교통,수송 > 교통시설 > **고속,시외버스정류장** |
| 명륜아이파크1단지 | 버스정류소 | 동래고교시외버스정류소(959m) | 교통,수송 > 교통시설 > **고속,시외버스정류장** |
| 해운대동백두산위브더제니스 | 버스정류소 | 해운대시외버스정류소(1073m) | 교통,수송 > 교통시설 > **고속,시외버스터미널** |

추가로 부산 최대 환승거점인 **서면역 인근(도보권에 시내버스 정류장이
수십 개 있는 지역)**에서도 동일 검색을 재현했으나 `버스정류장`/`정류장`/
`버스정류소` 전부 **"서면심야버스정류장/정류소"(고속,시외버스정류장으로
분류된 특수 명칭) 1건만 반환**됐다 — 위치의 버스 밀도와 무관하게 일반
시내버스 정류장 자체가 Kakao Local의 검색 가능한 POI로 존재하지 않는다는
것을 뒷받침한다.

### E. 오탐 여부

일반 업체/버스회사/전세버스가 섞이는 것이 아니라, **애초에 검색 결과가
나오지 않거나(대다수) 나오더라도 전혀 다른 교통수단(고속·시외버스
터미널)만 잡힌다.** "일반 규칙으로 걸러낼 오탐"이 아니라 "찾으려는
대상 자체가 인덱스에 없는" 문제라서, STEP 41처럼 `category_name` 패턴
필터로 해결할 수 있는 성격이 아니다.

## 향후 점수체계/이집 브리핑에서 재사용 가능한 값

현재는 **없음.** `nearestBusStopDistance`/`busStopCountWithin300m`/
`busStopCountWithin500m` 모두 신뢰 가능한 원시 데이터가 없어 산출
불가능하다. 후보 1(부산버스정보시스템) 또는 후보 2(TAGO)를 실제로
연동해야 이 값들을 계산할 근거가 생긴다.

## 알려진 한계

- 이번 조사는 REST API 직접 호출(Kakao JS SDK와 동일 백엔드)만
  사용했다 — 브라우저 JS SDK로 재확인해도 결과가 다를 이유는 없지만,
  실제 라이브 브라우저 재현은 하지 않았다.
- 표본 6개 단지 + 서면역 1곳 추가 검증(총 7곳)으로 결론을 내렸다 —
  전국/부산 전 지역을 전수조사한 것은 아니다.
- TAGO API의 부산 지원 여부, 노선번호 오퍼레이션의 실제 응답 스펙은
  페이지 열람만으로는 확정할 수 없고 서비스키 발급 후 실제 호출이
  필요하다.

## 최종 판단

Kakao Local API만으로는 일반 시내버스 정류장을 검색할 방법이 없음을
6개 표본단지 + 서면역 추가 검증으로 확인했다(오탐이 아니라 결과 자체가
없거나 다른 교통수단만 잡힘). "버스 카드가 화면에 생겼다"를 성공
기준으로 삼지 않고, 화면을 억지로 만들지 않은 채 필요한 공공 API 2종
(부산 전용 vs 전국) 후보를 조사해 보고하는 선에서 이번 STEP을
마무리한다. 신규 API key 발급은 사용자 승인 전까지 진행하지 않는다.
commit/push 하지 않았다.
