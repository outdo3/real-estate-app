# Detail Price Chart V2.2 — Full Width Mobile

On screens up to 420px, the detail panel no longer visually contains the price chart. The chart uses the page safe margin only; its header, period controls, legend, plot, and summary remain in one semantic section. Desktop keeps the existing panel treatment.

The chart continues to preserve V2 data semantics, volume axes, and the V2.1 pointer-focus versus keyboard-focus behavior.
