# 이집(ejip) 프로젝트 개발 로드맵

## 프로젝트 비전

이집은 단순히 부동산 정보를 많이 보여주는
플랫폼을 목표로 하지 않는다.

사용자의 조건과 취향을 바탕으로

"나에게 맞는 집을 골라주는 부동산 플랫폼"

을 목표로 한다.


## 제품 포지셔닝

제품 방향을 다음과 같이 정의한다.

호갱노노:
집과 단지를 탐색하고 정보를 확인하는 경험

아실:
부동산 데이터를 분석하고 비교하는 경험

이집:
사용자에게 맞는 집을 선택하고 추천하는 경험

※ 위 문구는 경쟁사를 평가절하하는 의미가 아니라
이집의 제품 방향을 구분하기 위한 내부 정의이다.


## 핵심 제품 철학

사용자가 이집을 사용한 뒤 최종적으로

"그래서 나는 어떤 집을 보면 되는가?"

라는 질문에 답을 얻을 수 있어야 한다.


## 핵심 차별화 후보

향후 검증을 전제로 다음 기능을 핵심 차별화 후보로 둔다.

1. 이집 단지점수
2. 나와의 궁합
3. 개인 맞춤 아파트 추천
4. 추천 TOP 5
5. 추천 이유
6. 아쉬운 점
7. 사용자 조건 기준 단지 비교
8. 추천 결과 지도 연동


주의:

위 기능과 점수체계는 아직 확정된 구현 사양이 아니다.

향후 데이터 검증과 설계를 거쳐 확정한다.


## AI 사용 원칙

Gemini/OpenAI 등의 생성형 AI를
추천 시스템의 필수 기반으로 만들지 않는 방향을 우선 검토한다.

가능한 기능은

데이터
+
규칙
+
자체 추천 알고리즘

으로 구현한다.

생성형 AI는 향후 필요성이 검증된 영역에서
선택적인 보조 기능으로 사용할 수 있다.

현재 사용 중인 Gemini 기능은
STEP 1에서 실제 의존성을 조사한 뒤
유지/축소/변경 여부를 결정한다.


## 지역 확장 전략

기존 전국 단위 기능을 임의로 제거하거나 제한하지 않는다.

새로운 이집 추천 시스템은
데이터 품질과 추천 정확도를 검증하면서
지역별로 단계적으로 제공하는 방식을 검토한다.

초기 검증 후보:
부산광역시 서구

이후:
부산광역시 전체

장기:
전국
