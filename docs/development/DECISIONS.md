## 1. 이집을 개인 맞춤형 부동산 추천 플랫폼으로 발전

날짜:
2026-08-12

결정:

기존 부동산 정보/통계 기능을 최대한 유지하면서
이집의 핵심 차별화를

"나에게 맞는 집을 골라주는 경험"

으로 발전시키는 방향을 우선 검토한다.

배경:

기존 서비스에는 지도, 실거래, 통계, 비교 등
다양한 부동산 기능이 이미 존재한다.

향후에는 단순 기능 수 경쟁보다는
기존 데이터를 활용하여 사용자의 선택을
도와주는 방향을 강화한다.

## 2. 생성형 AI를 추천 시스템의 필수 의존성으로 만들지 않는 방향 검토

날짜:
2026-08-12

결정:

향후 추천 시스템은
데이터 + 규칙 + 자체 추천 알고리즘을
기본 구조로 우선 검토한다.

Gemini 등 생성형 AI는
필요성이 확인되는 영역에서 보조적으로 사용할 수 있다.

현재 Gemini 기능은 아직 제거하지 않는다.

STEP 1에서 현재 의존성을 조사한 뒤 결정한다.

상태:

검토 방향 확정

## 3. 사용자에게 노출되는 데이터의 신뢰성을 기능 개발보다 우선한다

날짜:
2026-08-12

결정:

실제 데이터가 아닌 임의 계산값이나 샘플값을
실제 통계처럼 사용자에게 표시하지 않는다.

데이터가 존재하지 않거나 확보되지 않은 경우
"데이터 없음", "준비 중", "확인되지 않음" 등으로
명확하게 표시한다.

특히 /school의 특목고 진학률처럼
실제 통계가 아닌 값을 실제 통계처럼 표현하는 기능은
추천 플랫폼 개발 전에 우선 수정한다.

이유:

이집의 향후 핵심 경쟁력은
추천 결과에 대한 사용자 신뢰이기 때문이다.

채택

## 4. 추천 시스템의 지역별 단계적 검증

날짜:
2026-08-12

결정:

새로운 추천 시스템은
초기에는 부산 서구를 검증 후보 지역으로 사용하고,
추천 정확도와 데이터 품질을 확인한 뒤
부산 및 전국으로 확대하는 전략을 검토한다.

기존 전국 서비스 기능을 제한한다는 의미는 아니다.
