### 1-4. 진학정보 특별 감사(§요청 5) — 결론: NOT_CONFIRMED

공식 설명에 **"학업성취"**라는 카테고리명은 확인됐다. 그러나:

- 이것이 "국가수준 학업성취도평가 결과"인지, "특목고/자사고 합격자
  수·비율"인지, "대학진학률"인지는 **필드 레벨에서 확인되지 않았다**
  (OpenAPI 개발자 가이드가 이미지 전용 PDF라 텍스트 추출 불가,
  schoolinfo.go.kr의 API 상세 목록 페이지는 JavaScript 동적 로딩이라
  자동 조사로 필드를 확정할 수 없었음).
- 대학진학률/특목고진학률을 이름으로 명시한 별도 데이터셋은 이번
  검색에서 **찾지 못했다**. 검색 중 발견한 유일한 근접 사례는
  "경기도 특성화고 졸업생 진로현황"(전국이 아닌 경기도 한정, 학교알리미
  본체 API가 아닌 개별 시도 자료로 보임) — 참고용일 뿐 확정 근거 아님.
- **결론: 진학률/학업성취도가 학교알리미 OpenAPI에서 기계적으로
  파싱 가능한 필드로 제공되는지는 이번 조사로 확정할 수 없다.
  "AVAILABLE"이라고 단정하지 않는다. NOT_CONFIRMED로 기록하고, 실제
  인증키 발급 후 표본 호출로만 확정 가능.**
- 웹페이지(학교알리미 사이트)에 진학 관련 화면이 보인다는 이유로 API에도
  있다고 가정하지 않았다(사용자 지시 원칙 준수). 스크래핑도 검토하지
  않았다.

### 1-5. NEIS vs 학교알리미 역할 분리(제안)

V1 audit(§8/§9)에서 이미 확인된 대로 NEIS `schoolInfo`는 학교
정체성(이름/코드/주소/설립구분/남녀공학/학교급)만 제공하고 학생수·
학급수·교원·진학·급식은 없다. 이번 조사로 확인된 학교알리미 카테고리와
겹치지 않는다(중복 필드가 발견되지 않음) — 아래 역할 분리가 실제
필드 기준으로도 타당해 보인다(최종 확정은 학교알리미 필드 레벨 확인
후):

| 영역 | source |
|---|---|
| 학교 identity/주소/설립구분/남녀공학/학교급 | **NEIS**(이미 연동됨) |
| 학생/학급/교원/시설/급식/공시통계 | **학교알리미**(신규, §1-3) |

### 1-6. schoolCode 매핑 가능성 — UNKNOWN

학교알리미 자체의 학교 식별자 필드명(예: NEIS `SD_SCHUL_CODE`와
동일한지, 별도 코드 체계인지)은 이번 조사로 확인되지 않았다. 실무적으로
학교알리미도 교육부 산하 KERIS 운영이고 NEIS와 동일한 학교코드 체계를
공유할 가능성이 높다고 **추정은 되나, 확정하지 않는다** — 실제 API
응답을 받아봐야 확인 가능(§SCHOOL V2-B1 착수 시 최우선 확인 항목으로
제안).

### 1-7. 부산 coverage — 구조적으로는 전국 의무공시, 실측 미확인

학교알리미는 「교육관련기관의 정보공개에 관한 특례법」에 따라 **전국
모든 초·중·고·특수학교가 매년 1회 이상 공시할 법적 의무**가 있는
제도다(공식 설명 명시). 구조적으로 부산 667개교(NEIS 실측치, V1 §5)도
포함될 것으로 강하게 추정되나, **이번 조사에서 학교알리미 데이터를
실제로 내려받아 부산 표본 수를 세어보지는 않았다** — NEIS 667과의
직접 비교는 실제 데이터 확보 후 확인 필요(V1 §25에서 이미 unresolved로
표시된 항목, 이번 STEP에서도 미해소).

### 3-1. 우선순위 1 — 전국 통합 API 존재 확인(구별 API 불필요)

(`data.go.kr/data/15101155`)가 부산을 포함한 **전국 단위 통합 API**로
확인됐다 — §요청14가 우려한 "구별 API 파편화" 문제 자체가 발생하지
않는다(구청별 API 검토 불필요, 전국 통합 source가 이미 최상위 우선
후보).

- 제공기관: 한국사회보장정보원(보육서비스운영팀), 포털
  `info.childcare.go.kr`(보건복지부, "아이사랑")
- **이용허락범위: 제한 없음**(가장 자유로운 라이선스, 비용 무료)
- 트래픽: "해당 기관 정책에 따라 상이" (구체적 수치 미확인)
- 인증키 신청 절차/업데이트 주기: 이 페이지에서 명시적으로 확인되지
  않음(공공데이터포털 표준 절차 — 회원가입 후 활용신청 — 를 따를
  것으로 추정, 확정 아님)

### 3-2. 제공 필드

data.go.kr 페이지 직접 조회에서는 "시설명, 시설코드, 주소, 전화번호,
팩스번호, URL, 정원"만 명시적으로 확인됐다. 추가로 검색 과정에서
발견한 상세 필드 정보(공식 페이지 요약 기반, 원문 직접 대조는
못 했음 — **참고 수준으로 표기**): 시도, 시군구, 어린이집명,
**어린이집유형구분**, 운영현황, 우편번호, 주소, 전화번호, 팩스번호,
보육실수, 보육실면적, 놀이터수, **CCTV설치수**, 보육교직원수,
**정원수, 현원수, 위도, 경도**, **통학차량운영여부**, 홈페이지주소,
인가일자, 휴지시작/종료일자, 폐지일자.

**평가등급은 이 필드 목록에서 확인되지 않았다** — 별도 기관(한국보육
진흥원 평가인증 사무국으로 추정)의 source일 가능성이 있으나 이번
조사 범위에서 확인하지 못함(UNKNOWN, 후속 조사 필요).

포털(`info.childcare.go.kr`) "어린이집 공시개요" 페이지에서 별도
확인된 공시항목: 명칭/시설현황, **반수·원아수·직위별 교직원현황**,
교육과정 편성·운영, **보육료 수납현황**, 회계 예·결산서, 아동
건강검진현황, 환경위생관리현황, 사고발생현황, 급식현황, 안전점검현황,

## 4. Attendance Zones(통학구역/배정)

### 4-1. 공식 source 확인 — 존재함

- **학구도안내서비스(GIS)**: `schoolzone.emac.kr` — 교육부 산하 서비스로
  추정(운영기관 명시 페이지는 별도 확인 안 됨). "공공데이터 목록",
  "공공데이터 개방 대상" 페이지 별도 운영.
  - 개방 데이터: **초/중/고 모두 포함** — "학교 위치, 통학구역,
    학구·학군, 학교군, 비평준화지역, 교육행정구역, 학교-학구도 연계정보"
  - 형식: **CSV, SHP(공간정보/폴리곤 포함)** — 실제 통학구역 경계
    도형을 얻을 수 있는 유일하게 확인된 source
  - 이용허락조건/인증키 필요 여부: 이번 조사로 확인 안 됨

- **전국초등학교통학구역표준데이터**(`data.go.kr/data/15021149`)
  - 근거 법령: 초·중등교육법 시행령 제16조
  - 필드: 학구ID, 학구명, 학구분류, 시도코드, 시군구코드,
    시도교육청코드/명, 교육지원청코드/명, 생성일자, 변경일자,
    **공간객체ID**(공간정보 연계 가능성 시사, 실제 SHP는 별도)
  - 형식: XLS/XML/JSON/RDF/CSV(공간 파일 자체는 이 데이터셋에 없음 —
    학구도안내서비스의 SHP와 조합 필요)
  - **부산 포함 확인됨**(데이터 목록에 부산광역시교육청, 동래교육지원청
    등 확인)
  - **초등학교만** — 중학교 배정권역은 이 표준데이터셋에는 없음
  - 라이선스: 확인 안 됨

### 4-2. 중학교 배정권역

data.go.kr 표준데이터는 초등 전용이지만, **학구도안내서비스는
"학교군"(중학교 배정 단위의 통상 명칭) 항목을 명시**하고 있어 중학교
배정권역도 이 서비스를 통해 얻을 수 있을 것으로 보인다 — 단, 필드
레벨/파일 다운로드 실제 확인은 하지 않았다(UNKNOWN 수준 확정).

### 4-3. 결론

통학구역/배정권역은 스크래핑 없이 **공식 GIS 서비스 + 공공데이터포털
표준데이터 조합으로 확보 가능성이 높다** — SCHOOL V2-C(거리/경로
정확도) 이전에 별도로 다룰 가치가 있는 예상보다 좋은 source. 다만
라이선스·정확한 필드는 미확정이라 TIER 2로 분류(§7).

### TIER 분류

**TIER 1 — 반드시 연동**
- 어린이집 전국 정보 API(`15101155`) — 전국통합·라이선스 제한없음·
  좌표/유형/정원현원 모두 확인, 마찰 가장 적음
- 유치원 통합현황 파일데이터(`15037485`) — 라이선스 제한없음, 학급수/
  원아수/교직원현황 확인됨
- 학교알리미 학생/학급/교원 공시자료 — V1에서 식별된 최대 gap(NOT_FOUND
  대부분)을 메우는 유일한 source, 단 **라이선스 재확인(제1유형 경로
  선택) 선행 필요**

**TIER 2 — 있으면 강력**
- 학구도안내서비스(통학구역/배정권역) — 예상보다 잘 갖춰진 공식 GIS,
  SCHOOL V2-C보다 먼저 검토 가치 있음
- 유치원알리미 OpenAPI 나머지 항목(통학차량/방과후 등, 상업이용 가능
  오퍼레이션만 선별)

**TIER 3 — 후속**
- 전국학원표준데이터(Kakao AC5 보완)
- 전국도서관표준데이터 / 도서관 정보나루
- NEIS 급식식단정보·학사일정(부가 정보, 기존 NEIS 키 재사용 가능성)
- 어린이집 평가등급(source 자체부터 재조사 필요)

**REJECT — 사용 안 함**
- 없음(이번 조사에서 명백히 부적합/유해로 확인된 source 없음). 단,
  모든 비공식 블로그/카페 기반 정보는 원칙적으로 REJECT(공식 문서
  교차확인 안 된 것은 채택하지 않음).

## 10. 비용

공식 문서로 확인된 범위만:

- 학교알리미/유치원알리미/어린이집/통학구역/학원/도서관 API 전부
  **가격 정보가 명시적으로 "무료"라고 확인된 곳은 어린이집 API 뿐**
  (`15101155`, "비용무료" 명시).
- 나머지는 공공데이터포털의 일반 원칙("공공데이터는 원칙적으로 무료")을
  따를 것으로 추정되나, 개별 페이지에서 명시적 가격 문구가 확인되지
  않은 곳은 추정하지 않는다.
- 트래픽 제한: 구체적 수치가 명시된 곳은 도서관 정보나루뿐(개발계정
  1,000). 나머지는 "기관 정책에 따라 상이" 수준의 정성적 언급만 있음.

## 12. MVP 범위 제안(갱신)

이번 조사 결과를 반영해 사용자 제안 구조(§요청24)를 다음과 같이

  (NOT_CONFIRMED 상태 그대로는 기능화 불가).
- **SCHOOL V2-B2**: 유치원(통합현황 파일, 라이선스 제한없음 확인된
  경로 우선) + 어린이집(전국 API) core. 두 source 모두 이번 조사에서
  가장 마찰이 적은 것으로 확인됨 — **B1보다 먼저 착수해도 되는 순서로
  재배치 제안**.

  의사결정에 더 직접적일 수 있어 순서 재검토 여지 있음.
- **SCHOOL V2-D**: 부모 의사결정 UX(기존 계획 유지).
- (신규) **SCHOOL V2-E**: 통학구역/배정권역(§4) — 예상보다 잘 갖춰진
  공식 GIS source가 확인되어 별도 STEP으로 승격 제안.
