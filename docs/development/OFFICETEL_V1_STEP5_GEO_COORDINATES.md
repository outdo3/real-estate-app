5A에서 "다른 주소끼리 좌표가 겹친 사례 0건"이라고 보고했으나, 그것은 **지번 기준으로만** 센 값이라 틀렸다. 적재 후 실좌표 기준 재측정 결과:

| 구분 | 건수 |

## 11. 런타임 지오코딩 금지 계약

현재 `src/components/KakaoMapEmbed.tsx`는 props가 `{address, jibunAddress?, type}`뿐이라 **렌더마다** `addressSearch(도로명) → addressSearch(지번) → keywordSearch(이름)` 캐스케이드를 실행한다(호출부는 `apt/[name]` 2곳).

오피스텔 지도/로드뷰는 **이 동작을 재사용하면 안 된다.** 요구 계약:

```
저장된 latitude/longitude
  → 지도 즉시 초기화 (지오코딩 요청 0)
  → Roadview도 같은 좌표 사용
  → 파노라마 없으면 "이 위치는 로드뷰를 제공하지 않습니다."
```

이번 STEP에서는 **감사만 했고 컴포넌트를 수정하지 않았다** — 소비처가 없는 상태로 prop을 미리 넣는 것보다, 지도 UI STEP에서 실제 사용처와 함께 도입하는 편이 안전하다.
