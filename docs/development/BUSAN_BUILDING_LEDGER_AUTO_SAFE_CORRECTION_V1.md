## 4. `parking_per_household` — 범위를 벗어난 발견과 확인

`parkingPerHousehold`는 계산값이 아니라 **저장 컬럼**이다.

| 읽는 곳 | 출처 |
|---|---|
| 단지 상세 · AI 검색 | `parkingCount / totalHouseholds` **재계산** |
| 리포트 · stats/large-complex · compare V2 · **주차 Score** | **저장된 `parking_per_household`** |

세대수만 고치면 DB가 `parking_per_household ≠ parking_count / total_households` 상태로 남고, 상세만 정상화되고 리포트·통계·비교·점수는 계속 41.33 같은 값을 읽는다. 승인 목록에 없는 컬럼이라 **임의로 쓰지 않고 사용자에게 확인**했고, 파생 불변식까지 맞추도록 확인받았다.

- 적용: `parking_per_household = parking_count / 새 세대수` — **`parking_count`는 읽기만 한다**
- **이미 값이 있는 행만** 고쳤다(30건). 비어 있는 12건은 채우지 않았다 — null 채우기는 보정이 아니라 새 범위다
- 사후 검증: 214건 전체에서 불변식 위반 **0**
