## 3. KPI · 중앙가격 결정

- 상단 4칸: **거래건수 · 많이 거래된 가격대 · ㎡당 중앙가격 · 거래량 변화**(통계 화면과 같은 네 칸). 동은 증감 대신 매매 중앙가격(기존 판단 유지 — 표본이 작다).
- 매매 중앙가격 A/B/C 비교(실측 폭 1000px·A4 794px·360px):
  - A 유지(5칸): A4에서 3+2로 갈라지고 360px에서 3줄 → 첫 화면에 지역 비교가 안 들어온다.
  - **B 하단 상세로 이동(채택)**: 4칸 한 줄(A4·인쇄 `kpiGrid4`), 값은 "가격 상세"에 그대로. SEO 설명이 약속하는 "중앙 거래가"도 화면에 남는다.
  - C 제거: 데이터 삭제 금지 원칙 + SEO 설명 불일치 → 제외.

## 4. 데이터 모델 (새 조회 없음)

`buildRegionReport`가 이미 읽은 같은 행에서 통계 화면과 **같은 함수**로 계산해 `envelope.data`(`RegionReportData`)에 싣는다.

| 필드 | 함수 | 통계 화면 |
|---|---|---|
| `priceKpi` | `buildSalePriceKpi` | `salePriceKpiByPeriod[preset]` |
| `regionPrice` | `buildRegionPriceComparison`(부산: 16개 구·군, 구: 기간 행의 동) — 거래 있는 지역만 | `regionPriceByPeriod[preset]` |
| `summaryLine` | `buildSummaryLine` — 사실 문장만(평가·전망 없음), 5건 미만이면 가격대 문장 생략 | — |
| 지표 `topPriceBand` | 동률 모두, 3개 이상 "한 가격대로 모이지 않음", trust는 중앙가격과 같은 표본 게이트(완전성 판정 불변) | 가격대 카드 |

- 기간 밖 행은 builder 입구에서 한 번 더 자른다(정상 입력에서는 무변화) — 건수·최근 실거래·가격대·지역 평균이 같은 행 집합.
- 웹·A4 PNG·PDF·인스타 PNG가 모두 이 envelope 한 벌을 읽는다.

## 5. 지역 비교 · 표본 적음

- 부산 전체 → 구·군별, 구 → 동별 평균 매매가격 TOP5. 각 행: 지역명 · 평균 매매가격 · 거래건수 · (보조) ㎡당 평균.
- `regionPriceTop`: 5건 이상은 평균가 순위 최대 5, 1~4건은 남는 자리만 "거래 5건 미만 · 참고용" 묶음(순위 없음, 흐리게), 전체 5행 고정. 넘치는 표본 적음 지역 수는 안내 문구로.
- 정렬은 통계 화면 결과를 그대로 자른다(순위 재계산 없음).

## 6. 거래 많은 단지 · 동률

- 유효 행 하나 = 한 건(대운스카이뷰1차 30일 46건 — 부산 30일 리포트·인스타 이미지 1위 46건 확인).
- 발견: 통계 API는 건수만으로 정렬해 동률 순서가 DB 조회 순서였고, 리포트(최근 계약일 → 이름)와 5위가 달랐다(부산 15일: 동원로얄듀크 vs 사직쌍용예가, 둘 다 6건 / 서구 30일: 대신푸르지오1차 vs 서원블루오션G동, 둘 다 2건).
- 수정: 공용 `compareTopComplex`(건수 desc → 최근 계약일 desc → 이름 asc)를 리포트와 `/api/stats/concentration`(sort=count)이 함께 쓴다. **건수는 불변, 동률 안의 순서만 고정.** 캐시는 거래 행을 저장하고 정렬은 그 뒤라 키 변경 불필요.

## 7. 레이아웃

표준(웹/A4 PNG/PDF): 헤더 → 한 줄 요약 → KPI 4칸 → [지역 평균가격 TOP5 | 거래 많은 단지 TOP5] → [최근 실거래 | 분포(웹)·가격 상세·2년 최고가] → 해석 → 출처/기준일. 동: [거래 많은 단지 | 가격 상세·2년 최고가] → 최근 실거래(한 단).
문서 밀도: KPI 4칸 한 줄, 최근 실거래 3건 + "최근 거래 일부 표시" 안내, 분포 제외(`data-export-hide`) → 부산 15일 A4 PNG 1080×1528(1 : 1.415, 변경 전과 같은 크기). 수정 전 첫 시도는 1080×1772였다.

## 8. 인스타 피드 4:5

- `RegionInstagramCard`(1080×1350 CSS px, 1배): 헤더(브랜드·기간 칩·지역명·날짜 범위) → 한 줄 요약 → KPI 2×2 → [지역 평균가격 TOP5 | 거래 많은 단지 TOP5](동: [단지 | 최근 실거래]) → 푸터(이집 E-JIP · 복잡한 부동산, 이집으로 쉽게 · 데이터 기준일·완전성 · 출처 · 짧은 기간 신고 시차 안내).
- 단순 축소가 아니라 전용 배치. 외부 리소스(이미지·웹폰트) 없음 — 로고는 제품과 같은 텍스트 워드마크 + CSS 배지.
- `captureElementToFixedPng`: 정확히 outW×outH 캔버스, 비율 다르면 실패, 인스타 캡처만 말줄임(overflow) 유지(`keepOverflow`, A4 경로 불변).
- `InstagramExportStage`: 누른 뒤에만 `next/dynamic(ssr:false)`로 로드, 화면 밖에 그려 굽는다. 카드·본문 `scrollHeight`로 넘침을 검사해 **잘린 이미지를 저장하지 않고 실패로 알린다**(서구 15일 초안에서 목록이 푸터와 겹친 것을 이 검사로 잡음). 가려진 탭에서 rAF가 멈추는 문제(실측 20초+)는 120ms 타이머 경주로 해결.
- 파일명: `e-jip-busan-15d-2026-09-19-instagram-4x5.png`(기본 이미지 파일명 + 접미사).
- 스토리 9:16(1080×1920) readiness: 카드 구조(헤더·KPI·목록·푸터)와 캡처 함수는 크기 인자만 바꾸면 재사용 가능. 다만 세로 570px 여유를 채울 배치(목록 10행 또는 최근 실거래 추가)와 안전영역(상하 250px UI 겹침) 설계가 필요해 V1에서는 구현하지 않음 → FOLLOW_UP.

## 9. 다운로드 UX

지역 리포트의 [이미지] 버튼이 저장 메뉴를 연다: **기본 이미지**(한 장 리포트 PNG) · **인스타 피드용**(1080×1350 PNG · 4:5) · **PDF**(인쇄 창). 액션바 4칸·라벨·아이콘·aria-label은 그대로, [PDF] 버튼도 그대로. Escape·바깥 탭으로 닫힘. 단지·비교·일별 리포트의 [이미지]는 예전처럼 바로 저장(메뉴 없음 — 단지 리포트 실측 확인).
