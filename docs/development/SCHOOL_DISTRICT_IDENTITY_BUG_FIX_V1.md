## 1. Root cause — **시/군/구가 비면 시/도 전체를 열어 주는 fail-open 한 줄**

`src/lib/neis-sido-codes.ts` (수정 전)

```ts
export function addressMatchesRegion(addr: string, region: string, gungu: string): boolean {
  if (!addr) return false;
  const tokens = addr.split(/\s+/);
  if (addr.includes(region)) return true;   // ← 이 줄
  return tokens.includes(gungu);
}
```

토큰 완전일치(`tokens.includes(gungu)`)는 **맞게 짜여 있었다.** 문제는 그 **앞에 있던 지름길**이다.

시/군/구가 비면 `region`이 `"부산광역시 "`(뒤 공백)가 되고, `addr.includes("부산광역시 ")`는
**부산의 거의 모든 학교 주소**에 대해 참이다. 실측(NEIS 부산 671곳):

| region | gungu | 통과 건수 |
|---|---|---|
| `"부산광역시 "` | `""` | **663 / 671** |
| `"부산광역시"` | `""` | **670 / 671** |

**서로 다른 구의 학교가 한 화면에 동시에 나오는 경로는 이것뿐이다.** 보고된 4곳도 한 구에 모여 있지 않다 —
명지3고는 부산진구 주소, 명지3중·4중·6초는 북구 주소다. 구 필터가 정상이면 **절대 함께 나올 수 없다.**

### 언제 시/군/구가 비는가

| 경로 | 값 |
|---|---|
| `src/contexts/RegionContext.tsx:48` `FALLBACK_REGION` | `sigungu: ''` — **구를 고르기 전 기본 상태** |
| `src/components/RegionSelectModal.tsx:98` | `sigungu: ''` — **"부산광역시 전체"** 선택 |

`buildRegionDisplayName({ sido:'부산광역시', sigungu:'', dong:'all' })` = **"부산광역시 전체"**.
즉 기본 상태이거나 "전체"를 고른 상태에서 학교 화면에 들어가면 **부산 전체 학교가 한 목록에** 쏟아졌다.

## 4~6. Fix — 코드 수정(DB 수정 불필요)

**fix type: 코드 필터 + 정규화 계약.** DB에 저장된 값이 아니라 외부 API 응답을 거르는 로직이라
**DB write가 필요하지 않다**(§5 답: **아니오**).

**(1) 완전일치만 — fail-open 제거**

```ts
export function addressMatchesRegion(addr: string, _region: string, gungu: string): boolean {
  if (!addr) return false;
  if (!gungu || !gungu.trim()) return false;      // 구를 모르면 0건 (전 지역 개방 금지)
  return addr.split(/\s+/).includes(gungu.trim());
}
```

**(2) (가칭) 레코드 제외** — `isTentativeSchoolRecord()`. 개교해서 NEIS가 실제 주소를 채우면
`(가칭)`이 빠지며 **자동으로 다시 포함**된다(영구 배제가 아니다).

**(3) 목록·요약 카드가 같은 판정을 쓰도록** `schoolBelongsToRegion()` 하나로 모았다(§11).

**(4) 이름 기반 예외 제거** — 대신여자중·대신초·부산대신중 **셋 다 주소가 "부산광역시 서구 …"** 임을
실측했다. 주소 규칙만으로 정상 포함되므로 예외가 불필요하다.

## 15. 남은 학교 blocker

1. **(가칭) 학교의 실제 소재 구를 표시할 방법이 없다.** NEIS가 주는 주소가 사무소라서,
   "강서구에 명지3중이 생긴다"를 말하려면 **다른 출처**(교육청 설립 고시 등)가 필요하다.
   지금은 **표시하지 않는 것**이 정확한 선택이다.
2. **학업성취도·진학률·학급당 인원은 여전히 "데이터 준비 중"** — NEIS에 없는 값이라 지어내지 않는다(기존 정책).
3. **학원 수(`academyCount`)는 카카오 API 한도로 최대 45건까지만 실집계**된다. 구 중심좌표 조회 실패 시 `-1`.
4. 이 필터는 **부산 밖 지역에도 그대로 적용**된다(서울·경기 등). 이름 충돌 패턴은 전국적으로 존재하므로
   (예: 서울 중구/서울 성동구) 같은 규칙이 필요하고, 이미 동일하게 동작한다.
